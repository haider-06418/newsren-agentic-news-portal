# Roadmap

## Phase 0 - Foundation

- [x] Confirm product boundary and initial desks.
- [x] Select a lightweight provider-agnostic architecture.
- [x] Scaffold the web application.
- [x] Document editorial and AI decisions.
- [x] Create and push the public GitHub repository.
- [x] Register the private development deployment.

## Phase 1 - Editorial experience

- [ ] Build the responsive homepage and desk navigation.
- [ ] Add the flagship Education & Immigration story.
- [ ] Model sources, evidence, claims, and timeline events.
- [ ] Add evidence and editorial-status UI.

**Gate:** The story can be understood and audited without invoking a model.

## Phase 2 - Story intelligence

- [ ] Implement the provider adapter and deterministic demo provider.
- [ ] Add AI Story Brief.
- [ ] Add the contextual Ask Newsren pane.
- [ ] Add source-grounded response validation and abstention.

**Gate:** Every generated material claim is supported or explicitly marked uncertain.

## Phase 3 - Learn and follow

- [ ] Add student, educator, and professional explanation modes.
- [ ] Save follows locally.
- [ ] Demonstrate material-change detection with seeded updates.

**Gate:** A user can discover, understand, investigate, and follow one question end to end.

## Phase 4 - Evaluation and release

- [ ] Add trust, usefulness, accessibility, latency, and cost checks.
- [ ] Complete responsive browser QA.
- [ ] Publish the demonstration site.
- [ ] Record a short demo and architecture walkthrough.
