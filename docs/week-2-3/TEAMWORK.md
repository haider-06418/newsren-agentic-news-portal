## Pair-programming protocol

For each code session:

1. Record the task and expected outcome before coding.
2. Assign one human as driver and one as navigator.
3. Switch roles at least once during the session.
4. Record what each person taught or learned.
5. Link the resulting commit or pull request.
6. Add `Co-authored-by` metadata when a commit genuinely represents paired work.

The linked course guidance is reflected by using active driver/navigator roles, frequent role rotation, and pairing on complex or knowledge-transfer tasks.
